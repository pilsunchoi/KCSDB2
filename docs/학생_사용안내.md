# 학생 사용 안내 — KCSDB2 무역통계 DB

이 DB는 관세청 무역통계(2007.01–2026.03, 2,753만 거래행)를 분석용으로 가공한 것이다.
로컬 주피터 노트북에서 분석한다.

---

## 1단계 — 패키지 설치

터미널(명령 프롬프트/PowerShell/터미널)에서:
```
pip install duckdb pandas matplotlib jupyter
```
재구축이 아니라 분석만 하므로 이 4개면 충분하다. conda·특정 파이썬 버전 불필요.

---

## 2단계 — 저장소 받기

GitHub에서 이 저장소를 clone 또는 ZIP 다운로드 후 압축 해제.

---

## 3단계 — DB 받아서 배치

저장소에는 DB가 없다(GitHub 100MB 한도 초과). **Releases 페이지**에서 압축된 DB
(`kcsdb.duckdb.gz`)를 받아 압축을 풀고 `data/processed/kcsdb.duckdb`에 놓는다.

압축 해제:
- Windows: 7-Zip 등으로 .gz 해제
- Mac/Linux: `gunzip kcsdb.duckdb.gz`

---

## 4단계 — 주피터 실행

저장소 루트에서:
```
jupyter notebook
```
브라우저가 열리면 `notebooks/analysis_start.ipynb`를 연다.
셀을 위에서부터 실행하면 접속·구조 확인·기술통계 시연이 순서대로 나온다.

## DB 구조 (분석 시작 전 필독)

- **fact_trade**: 거래(국가×HS10×월). yyyymm, stat_cd, hs10, exp_dlr, imp_dlr, exp_wgt, imp_wgt, bal_payments
- **fact_total**: 국가×월 총계. HS 없음.
- **dim_country**: stat_cd → 국가명·ISO·대륙
- **dim_hs10**: hs10 → 품목명·단위·발효일
- **dim_hs6_concordance**: HS 개정 간 연결, 6자리(hs2022 ↔ 과거코드). 관세청 공식 연계표
- **dim_hs10_to_2022**: HS 개정 간 연결, 10자리(과거코드 → hs2022 + 가중치). 공식 자료가 없어 **추정한 것**
- **dim_hs10_concordance**: 개정 하나(2012·2017·2022)를 건너는 10자리 연결. 위 표의 재료

금액 단위: 미화 달러(USD). 중량 단위: kg.

## 분석 시 반드시 알아야 할 함정 (docs/세션_발견_노트.md 상세)

- **HS 개정 연결**: 2022 개정으로 코드가 바뀐 품목은 코드 동일성만으로 시계열이 끊긴다.
  8524122000(평판 디스플레이 모듈)은 원자료에서 2022년 1월에 무에서 생겨나는 것처럼 보이지만,
  실제로는 8517701023 등에서 옮겨 온 물량이다. 2022년 개정 하나로 수출액의 13~14%가 코드를 옮겼다.
  - 6자리로 충분한 분석: `dim_hs6_concordance`로 hs6를 통일한 뒤 수행한다.
  - 10자리가 필요한 분석: `dim_hs10_to_2022`를 조인하고 금액에 `weight`를 곱한 뒤 `hs2022`로 다시
    집계한다. `past_version`은 2011년까지 '2007', 2012~2016년 '2012', 2017~2021년 '2017'을 쓰고,
    2022년 이후 자료는 이미 현행 체계이므로 변환하지 않는다. **`method='chain'`으로 걸러야
    10자리 해상도가 유지된다**(`hs6_fallback`은 6자리로 흩뿌린 보완분이다).
  - 다만 10자리 연계는 공식 자료가 아니라 추정이다. 나뉜 비율은 개정 직후 6개월 수출액에서
    계산한 값이지 관세청이 알려 준 값이 아니다. 논문에 쓸 때는 이 점을 밝힌다.
- **음수 중량 19행**: 관세청 사후 정정 원본. 단가(금액/중량) 계산 시 이상치.
- **범위 경계**: 데이터는 202603까지. 2026은 부분년(1-3월)이므로 연도 비교 시 제외한다.
- **폐지코드**: hs10의 27.2%는 dim_hs10에 품목명이 없다(폐지코드). HS6 수준 분석은 무영향.
