## 0. 방향 정정 (중요)

이 문서는 원래 **방향 B**(외부 렌더 HTML·노트북으로 링크만 거는 인덱스 페이지)를 상정했던 것으로
알려져 있으나, 이번 산출물의 실제 방향은 **방향 A — DB 소개 단일 HTML 대시보드**다.

- **방향 A (채택):** DB가 무엇이고 / 어떻게 만들어졌고 / 어떤 함정이 있고 / 어떻게 받아 쓰는지를
  한 페이지 안에서 설명하는 자기완결형 소개 대시보드. 콘텐츠는 저장소 문서에서 발췌·재구성하며
  새로 창작하지 않는다.
- **방향 B (부분 유지):** 외부 링크 인덱스 방식은 **"연구" 탭에서만** 유지한다. 연구 탭의 챕터
  카드가 외부 렌더 HTML·노트북으로 링크를 거는 방식이 방향 B에 해당한다. 나머지 4개 탭은 방향 A다.

## 1. 형식·테마

- 단일 `.html` 파일, CSS·JS **인라인**, 외부 CDN 의존 없음(오프라인 열람 대비).
- light 테마, 모바일 반응형(기준폭 약 380px 검증).
- 탭 전환은 프레임워크 없는 vanilla JS(버튼 클릭 → 섹션 show/hide).

## 4. 콘텐츠 원칙

- **새로 창작하지 않는다.** 모든 텍스트는 저장소 문서에서 발췌·재구성한다.
- 근거 문서에 없는 항목은 싣지 않는다. (예: 함정 탭에서 "코소보 API 영구 실패 / cp949 인코딩 /
  개정 81.5–82.8%"는 문서 근거가 없어 **제외**하고, 세션_발견_노트.md의 실재 함정으로 대체.)
- concordance·hs10 커버리지 WARN 수치는 세션_발견_노트.md 0절 봉인에 따라 "종수·가정적 상한"과
  "거래액 실측 0.004~0.007%"를 병기한다.
